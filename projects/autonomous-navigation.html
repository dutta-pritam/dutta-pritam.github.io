Autonomous Navigation

2026 · Robotics, Path Planning, SLAM, Python

A Python and matplotlib simulation of a differential-drive robot navigating an obstacle-dense field.

It began from an earlier “Phase 1C” script — featuring a random obstacle field, wheel encoders, and a 180-ray LiDAR sweep rendered as a live animation — which I extended in two major directions: real-time path planning toward a dynamic goal using LiDAR returns, and SLAM-style occupancy-grid mapping built up from those same scans.

I also scaled up the obstacle count from 18 to 100 to rigorously stress-test the planner in high-density clutter.

Simulation Output

Live simulation showing LiDAR raycasting, real-time occupancy grid updates, and A* path replanning through 100 random obstacles.

Core Features

  • Differential-Drive Kinematics: Accurate modeling of robot velocity, heading updates, and wheel encoder noise.
  • 180-Ray LiDAR Simulation: High-resolution raycasting to detect boundary intersections and obstacle ranges within a 360-degree field of view.
  • Occupancy-Grid Mapping: Probabilistic grid updates mapping free vs. occupied space based on sensor returns over time.
  • A* Path Planning & Replanning: Dynamic route calculation that reacts instantly to newly discovered obstacles in dense environments.

Implementation & Architecture

The simulator is implemented purely in Python using NumPy for vectorized math operations and Matplotlib for the real-time frame rendering loop. The architecture decouples the sensor layer, mapping layer, and planning layer:

  • Perception: Casts rays from the robot's current pose, computing intersections with circular obstacle geometries.
  • Mapping: Translates sensor hits into discrete grid cells using Bresenham's line algorithm to mark free space along the ray and occupied space at the endpoint.
  • Planning: Periodically feeds the updated occupancy map into an optimized A* graph search algorithm to chart the shortest collision-free trajectory to the target coordinates.
