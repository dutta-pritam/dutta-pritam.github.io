Autonomous Navigation

2026, Robotics, Path planning, SLAM, Python

A Python and matplotlib simulation of a differential-drive robot navigating a field of obstacles.

It began from an earlier “Phase 1C” script — a random obstacle field, wheel encoders, and a 180-ray LiDAR sweep rendered as a live animation — which I extended in two directions: path planning toward a goal using the LiDAR returns, and SLAM-style occupancy-grid mapping built up from those same scans.

I also raised the obstacle count from 18 to 100 to stress-test the planner in denser environments.
