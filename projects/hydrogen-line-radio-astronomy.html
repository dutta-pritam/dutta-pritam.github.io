Hydrogen Line Radio Astronomy

2026, Radio astronomy, SDR, Signal processing

A hydrogen-line (21 cm) radio astronomy pipeline built around a HackRF software-defined radio and the Virgo Python library, run from Kolkata.

Getting it working meant resolving issues across the observation parameters and the GNU Radio flowgraph wiring, and tracing a batch of corrupted .iq files back to two root causes: a missing integer-to-float conversion and USB buffer overflows, both of which were producing NaN and subnormal values in the recorded data.
